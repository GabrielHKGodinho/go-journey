"A goroutine has no return value, so an error inside it doesn't automatically reach whoever launched it. Manually, this is solved with an error channel, usually buffered to the number of goroutines, collecting everything to handle afterward — but that adds a fair amount of coordination code. In practice, I use errgroup: each goroutine is a function that returns an error, Wait handles the counting that a WaitGroup would otherwise do, and if any of them fails, the group's derived context is automatically cancelled, signaling the others to stop. Wait returns the first error found, which is enough for most cases where I just need to know something went wrong to decide the next step."
